## Installation comme application web

Le site peut être installé depuis un navigateur compatible après sa publication en HTTPS.

- **Android (Chrome)** : ouvrez le site, appuyez sur « Installer l’application » ou choisissez « Installer l’application » dans le menu du navigateur.
- **iPhone/iPad (Safari)** : ouvrez le site, appuyez sur « Partager », puis « Sur l’écran d’accueil ».
- **Ordinateur (Chrome ou Edge)** : ouvrez le site et utilisez le bouton « Installer l’application » ou l’option d’installation dans la barre d’adresse ou le menu du navigateur.

L’application conserve son interface et les fichiers de l’application pour permettre le rechargement hors connexion. L’import/export de documents et les ressources chargées depuis des CDN nécessitent une connexion Internet.
